# Como contribuir

Comece pelo README e pelas instruções do repositório em que você vai trabalhar. Eles definem instalação, convenções, validação e processo de revisão.

## Propor uma mudança

Descreva o problema, o comportamento esperado e o critério de conclusão na ferramenta de tarefas usada pelo projeto. Use os modelos de issue quando esse for o canal adotado.

Confira o trabalho em andamento e as decisões existentes antes de iniciar uma implementação.

## Abrir um pull request

Explique o comportamento anterior e o resultado da alteração. Inclua a tarefa relacionada, o procedimento de validação e o resultado observado.

Atualize a documentação quando houver mudança no modo de uso, na configuração ou na operação. Registre limites e pendências relevantes.

## Seguir o processo do projeto

Use os comandos, as branches e os procedimentos definidos no próprio repositório. Este documento fornece uma orientação geral; os contratos e as instruções específicos do projeto continuam sendo a referência.
