# Padrões de colaboração da Syntelix

Este repositório reúne a apresentação pública da organização e os padrões gerais de colaboração.

| Arquivo | Finalidade |
| --- | --- |
| [profile/README.md](profile/README.md) | Apresentação exibida no perfil público da Syntelix |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Orientações gerais para contribuir |
| [SUPPORT.md](SUPPORT.md) | Canais de contato e suporte |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Modelos para relatar problemas e propor mudanças |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | Modelo de descrição de pull request |

O GitHub utiliza os arquivos de comunidade suportados como padrão quando um repositório da organização não possui sua própria versão. Instruções e templates específicos de cada projeto continuam sendo a referência.

A presença destes arquivos não altera licenças, permissões, CI ou regras de branch dos projetos.
